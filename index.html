05 / Jesucrisis · Proceso

Collage inicial

Partí mezclando imagen, textura, logo y silueta. Esta prueba me sirvió para ver cuánto ruido visual podía soportar la pieza sin perder el nombre de la banda.

06 / Jesucrisis · Movimiento

Acá llevé la gráfica a un contraste más duro, usando la silueta como protagonista y haciendo que el movimiento apareciera por capas.

07 / Jesucrisis · Color

Variación azul

Probé una versión más fría para ver cómo cambiaba el tono. Mantiene la misma base, pero el color la hace sentirse más nocturna y pesada.

08 / Jesucrisis · Iteración

Versión depurada

En esta etapa reduje elementos y ordené mejor el fondo para que la silueta, el símbolo y la dirección de lectura quedaran más claros.

09 / Jesucrisis · Exploración

Dibujo y línea

Volví al dibujo y a una composición más clara para comparar legibilidad. Fue una forma de probar la identidad sin depender tanto del bloque de color.

Simplificación

Quité elementos para comprobar cuánto podía simplificar la composición sin perder carácter. Esa comparación también fue parte del desarrollo.

Identidad visual · Caso

Jabones Camii

Marca desarrollada por Diego Pazos

Una identidad pensada para funcionar en distintos formatos.

En Jabones Camii desarrollé la identidad visual de la marca a partir de un sello circular y un lettering de carácter artesanal. El proceso incluyó exploración cromática, versiones monocromas, ajustes del logotipo y aplicaciones sobre producto.

El objetivo fue construir una marca flexible: que pudiera conservar reconocimiento al cambiar de fondo, color o soporte, sin depender de una sola versión del logo.

01 · Exploración

Pruebas de color y contraste para definir el carácter del sello.

02 · Adaptación

Versiones monocromas y lineales para distintos soportes y sistemas de impresión.

03 · Aplicación

Pruebas sobre fotografía y producto para comprobar legibilidad en contexto.

04 · Consistencia

Zona de resguardo y variantes para mantener reconocimiento en diferentes usos.

Resultado

Una identidad que no depende de una sola versión.

El desarrollo dejó un pequeño sistema de marca: versiones a color, monocromas, firma, zona de resguardo y uso sobre fotografía. El lettering y la forma circular mantienen el reconocimiento cuando cambian los colores o el soporte.
