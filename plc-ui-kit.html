07 / Guidelines

Responsive y accesibilidad

ContextoRegla
EscritorioSidebar de navegación, dashboard modular y tarjetas en dos columnas.
TabletTarjetas reorganizadas, controles fluidos y navegación simplificada.
MóvilUna columna, importes legibles, controles táctiles de al menos 44 px.
FinanzasSeparar saldo, moneda, estado y acciones; no usar únicamente color para distinguir resultados.
AccesibilidadFoco visible, mensajes de error textuales, etiquetas y soporte de movimiento reducido.
Este UI Kit documenta los estilos existentes de PLC y propone estados adicionales para futuras iteraciones. No implica que exista integración bancaria, blockchain funcional o transacciones reales.
