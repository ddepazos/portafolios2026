# Portafolio 2026

Portfolio personal y estudio de casos de diseño, branding y desarrollo web.

## Objetivo

Presentar proyectos, procesos y referencias en una estética brutalista, clara y personal, manteniendo una buena legibilidad y una arquitectura de información coherente.

## Estructura

- `index.html`: portada del portafolio
- `css/`: estilos visuales y tokens del sistema de diseño
- `js/`: scripts de interacción
- `data/`: contenido estructurado de proyectos
- `proyectos/`: páginas de detalle por proyecto
- `assets/`: recursos gráficos y multimedia

## Proyecto activo

Este repositorio está pensado para desplegarse en GitHub Pages y enlazar cada proyecto con su versión pública o caso de estudio correspondiente.
